# متجر ديلمار ايجيبت 🌾

متجر إلكتروني لشركة **ديلمار ايجيبت للاستيراد والتصدير والتنمية الزراعية** — أسمدة ومبيدات ومستلزمات زراعية، بالدفع عند الاستلام.

المتجر مبني بكود بسيط ومملوك لنا بالكامل: HTML + CSS + JavaScript خالص، بدون أي مكتبات أو أدوات بناء. يعمل كتطبيق (PWA) ويُثبَّت على الموبايل.

## التشغيل محلياً (حتى على Termux)

المتجر يعمل مباشرة بفتح `index.html` في المتصفح. ولتجربة كاملة (مع خدمة PWA) شغّل خادمًا محليًا بسيطًا:

```bash
# بايثون (موجود في Termux)
cd dellmar-egypt.github.io
python -m http.server 8080
# ثم افتح http://localhost:8080
```

## هيكل المشروع

| الملف / المجلد | وظيفته |
|---|---|
| `index.html` | هيكل الصفحة الوحيدة (الترويسة، الشريط السفلي، التذييل) |
| `css/base.css` | التخطيط والمكوّنات المشتركة |
| `css/theme-harvest.css` | ثيم «الحصاد» المعتمد (الألوان فقط — عدّل هنا لتغيير الشكل) |
| `css/theme-premium.css` / `theme-fresh.css` | اتجاهات بديلة محفوظة للتجربة |
| `js/data.js` | بيانات المنتجات الـ 79 والتصنيفات |
| `js/config.js` | الإعدادات: رقم التليفون، مفتاح Web3Forms، الإيميل |
| `js/app.js` | منطق المتجر: التنقل، السلة، إرسال الطلب |
| `manifest.webmanifest` + `sw.js` | تثبيت المتجر كتطبيق (PWA) |
| `images/` | الشعار وصور التصنيفات وبطاقات المنتجات |
| `icons/` | أيقونات التطبيق |

## تعديل الألوان والشكل

كل الألوان معرّفة كمتغيرات CSS في أعلى ملف الثيم `css/theme-harvest.css` (مثلاً `--btn-bg` لون الأزرار). عدّل القيم هناك ويتغير المتجر كله.

لتجربة ثيم آخر مؤقتًا أضف `?theme=premium` أو `?theme=fresh` لرابط المتجر.

## الطلبات

الطلبات تصل على الإيميل عبر خدمة [Web3Forms](https://web3forms.com) (مجانية). المفتاح موجود في `js/config.js`. الدفع عند الاستلام فقط — لا توجد مدفوعات إلكترونية.

## النشر

المتجر منشور على GitHub Pages من هذا المستودع نفسه: أي `git push` لفرع `main` يحدّث الموقع خلال دقيقة تقريبًا.
